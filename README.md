# 🛡️ Spam-classifier - AI Message Security Analyzer

Cognix is an AI-powered spam and scam detection system that combines:
- Machine Learning (Naive Bayes + TF-IDF)
- Cybersecurity rule engine
- Risk analysis system

## Features
- Detects spam messages
- Identifies phishing patterns
- Provides risk level (Safe / Suspicious / Dangerous)
- Explainable output with reasons

## Tech Stack
- Python
- scikit-learn
- Streamlit
